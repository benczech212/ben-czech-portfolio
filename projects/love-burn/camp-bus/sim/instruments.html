A camp member's Monstera MIDI Plant: silicone leaves with LED filament and piezo sensor tape cast in, each stem ending in a TRRS jack into the trunk, mapped to bass synth patches. Piezo tape reads strain rate, so the bridge publishes bend at ~8 Hz with the flex as value while a leaf is being worked, and release when it springs back with the spike as velocity; a light tap is a small hit. MIDI out from this page
Two ways to reach Ableton. Bridge (the real one): python tools/midi_bridge.py --host localhost subscribes to every instrument on the bus and plays it into a loopMIDI port; works for real hardware and this page alike. Direct (dev shortcut): pick a port above and this page sends the same notes and CCs itself via Web MIDI (Chrome, localhost only). Don't run both into the same port or every note doubles. Hits and touches are notes with velocity on the pad's channel; hold and bend readings are CC 74; a plant release is the note with the snap as velocity.
